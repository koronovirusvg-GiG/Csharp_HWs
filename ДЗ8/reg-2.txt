б) по уммолчанию System.Text.Json.JsonSerializer смотрит на регистр и различает его. Надо отключить ему принудительную проверку через options:

var options = new JsonSerializerOptions
{
    PropertyNameCaseInsensitive = true
};

Game game = JsonSerializer.Deserialize<Game>(jsonString, options);

в) Является. можно написать через List<object>: 

string json = "[1, \"hello\", true, null]";
object[] items = JsonSerializer.Deserialize<object[]>(json);
