а) Какие поля/свойства попадут в JSON-строку, а какие нет?

Name и Score попадут. Это публичные (public) свойства с аксессорами { get; set; }

secretCode не попадёт. Это приватное поле. Сериализатор не имеет доступа к закрытым членам класса и по умолчанию не обрабатывает поля

IsAlive не попадёт. Несмотря на модификатор public, это обычное поле, а не свойство (у него нет { get; set; }). По умолчанию JsonSerializer игнорирует все поля класса

б) добавить над (private int secretCode = 42;) [JsonInclude]

в) 
 1) дописать аксессоры (public bool IsAlive { get; set; })
 2) добавить [JsonInclude] над (public bool IsAlive;)
